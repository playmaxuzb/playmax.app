PLAYMAX mobile app demo (installable PWA)
- Publish this folder's contents at the root of a GitHub Pages repository; see GITHUB-PAGES.md.
- On Android, install from the browser. On iPhone, open in Safari and use Share > Add to Home Screen.
- core.js contains catalog, languages, shipping estimates, recoloring and shared app logic.
- viewer3d.js and assets/ are included. The 3D viewer and web fonts need internet access.
- This is an installable web app, not a signed APK or App Store upload.
- Orders are sent by the customer through WhatsApp or Telegram to +93 77 990 1111 (no online payment).
- Marketplace posts are saved on the device only. Connect a server/database so everyone sees them.


LIVE CONTENT (NEW)
content.json is managed by the PLAYMAX Admin app (prices, new machines, photos, news, shipping, contacts). Do not delete it. Admin-uploaded photos are stored in assets/u/.
